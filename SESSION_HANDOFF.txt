What Changed This Session
- Added runtime display detection with NVS persistence in include/TFT_Setup_ESP32_S3_Thermostat.h.
: Detects 4-inch (480x320 ILI9488) vs 2.8-inch display at boot.
: Persists detected variant to NVS key "dispVariant" so next boot skips detection.
: dispW()==480 / dispH()==320 identifies the 4-inch variant.
- Unified all debug logging through debugLog() in src/Main-Thermostat.cpp.
: Last 4 remaining direct Serial.print() debug calls converted to debugLog().
: debugLog() writes to both Serial and the 64KB ring buffer (debugBuffer).
- Fixed /debug web console renderer (HTML/JS in src/Main-Thermostat.cpp).
: Root cause: renderer was displaying literal \n characters instead of line breaks.
: Added normalizeLogPayload() JS function to handle raw text, JSON {"log":"..."}, escaped string, and literal \n patterns.
: Changed log container from <div> to <pre> element so whitespace/newlines render natively.
: /debug page fetches from /api/debug/plain (plain text endpoint), not /api/debug (JSON).
- Fixed /api/debug crash (heap exhaustion on core 1) in src/Main-Thermostat.cpp.
: Root cause: /api/debug JSON endpoint was escaping the full 64KB buffer into AsyncResponseStream.
: AsyncResponseStream::write() resizes its internal cbuf dynamically; the full 64KB escape loop caused new() to throw.
: Fix: /api/debug now extracts only the last 8KB of the buffer (aligned to newline boundary) before escaping.
: /api/debug/plain is unaffected and still returns the full buffer as plain text.
- Released as tag 1.5.000 (commit 7b84991), pushed to origin.
